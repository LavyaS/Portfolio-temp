Deepfake Detection

A machine-learning classifier that flags manipulated video and image media, built around feature engineering and model evaluation rather than a single black-box call.

Problem

Manipulated media is increasingly hard to catch by eye. Most tooling either needs heavy infrastructure or returns an opaque yes/no with no visibility into confidence or failure modes.

Approach

Preprocessed and labeled a media dataset, engineered features suited to detecting manipulation artifacts, trained and compared classification models, and evaluated results on precision and recall — not accuracy alone.

Automation Reporting Dashboard

03

Web Scraping & Data Pipeline

A Python pipeline that collects data from web sources, cleans it, and outputs structured, analysis-ready data instead of raw HTML.

Problem

Useful data is often locked inside inconsistent web pages — no API, no fixed structure, and no guarantee the format stays the same twice.

Approach

Used Requests and BeautifulSoup to collect source pages, wrote parsing logic tolerant of inconsistent markup, then used Pandas to clean, validate, and export the result as structured data ready for analysis.
